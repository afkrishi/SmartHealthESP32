# SmartHealthESP32
💡 An ESP32-based health monitoring system using:
- Pulse Sensor (HW-827)
- ADXL335 Accelerometer (Step count)
- Temperature Sensor
- GPS Module
- Firebase Realtime Database

## 🔧 Features
- Real-time health data monitoring
- Wireless sync via WiFi
- Firebase integration for storage
